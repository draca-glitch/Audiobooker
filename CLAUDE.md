# audiobooker

## What this is
Multi-voice audiobook generator. Input: a chapter of prose + `cast.yaml`. Output: single M4B audiobook file with different voice per character (narrator + each character), optional sound effects, optional ambient SFX layered underneath.

- Local: `/root/work/audiobooker/`
- Python package, v0.2.0
- Sibling project to [DimensionDrift](/root/work/dimensiondrift/) (which is the actual prose this tool renders)

## Pipeline
```
chapter.txt + cast.yaml
   → LLM parser (Claude / any LLM) splits into segments per character, dialogue tags attributed
   → TTS render (Kokoro local / ElevenLabs cloud / hybrid) each segment → small WAV, per-segment pedalboard effects
   → ffmpeg concat all segment WAVs into single file with context-aware silence gaps
   → optional ambient SFX layer underneath
   → final M4B
```

## Config-driven
The whole project is driven by **one configuration file**: `cast.yaml`. Define which voices speak which characters, pronunciation overrides, per-character audio effects. Everything else is mechanical.

## TTS backends
- **Kokoro** — local ONNX TTS (default, no API key, no cloud). Runs on existing Kokoro setup on Epsilon.
- **ElevenLabs** — cloud TTS (higher quality for specific voice cloning, requires API key)
- **Hybrid** — mix of both per-character

## Where audiobook outputs go
- DimensionDrift renders: `/root/work/dimensiondrift/audiobook/` and served publicly at `https://eastblue.se/audiobook/` (via Plesk `httpdocs/public/audiobook/`)
